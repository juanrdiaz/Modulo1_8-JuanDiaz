# 🚀 Guía para tu Proyecto Web

¡Bienvenidos a su primer proyecto de desarrollo de software utilizando metodologías ágiles! En el mundo profesional, los desarrolladores no solo escriben código; también gestionan su tiempo, priorizan tareas y colaboran en equipo. Para lograr esto, utilizaremos las herramienta necesarias para de proyectos más usada en la industria tecnológica.

# ⏱️ El Reloj de 4 Semanas
## Cronograma de Sprints (1 semana por ciclo)

*   🏃‍♂️ **Sprint 1 (Semana 1): El Esqueleto**
    *   Diseño de interfaces (wireframes) y maquetación semántica pura en **HTML**.
*   🎨 **Sprint 2 (Semana 2): El Aspecto Visual**
    *   Hojas de estilo unificadas con **CSS** y adaptabilidad móvil (*Responsive Design*).
*   ⚡ **Sprint 3 (Semana 3): La Magia**
    *   Interactividad, lógica, manipulación del DOM y validaciones dinámicas con **JavaScript**.
*   🌐 **Sprint 4 (Semana 4): El Lanzamiento**
    *   Despliegue en la nube (GitHub Pages), control de errores de última hora y defensa del proyecto.

---

## Ideas de Proyectos Web (Ideales para HTML, CSS y JS)
Estas ideas están pensadas para que el alcance no se desborde en 4 semanas, pero que obliguen a los estudiantes a usar interactividad con JavaScript (manipulación del DOM, arrays y eventos).
1. **Catálogo de Adopción de Mascotas:** Filtros por tipo de animal (perro/gato), edad o tamaño, y un formulario interactivo para postularse como adoptante.
2. **Plataforma de Recetas de Cocina:** Buscador de recetas por ingredientes o tiempo de preparación, con opción de calcular las porciones dinámicamente con JS.
3. **Página de una Cafetería / Restaurante:** Menú interactivo donde el usuario simula agregar productos a un carrito y calcula el total del pedido en tiempo real.
4. **Sitio de Reservas para un Gimnasio o Barbería:** Un catálogo de servicios con un calendario interactivo en JS para seleccionar fecha, hora y "reservar" un turno.
5. **Dashboard de Finanzas Personales:** Una interfaz simple para ingresar ingresos y gastos mensuales, mostrando el saldo disponible mediante cálculos dinámicos.
6. **Enciclopedia Visual de Videojuegos o Películas:** Uso de tarjetas (cards) dinámicas con un buscador por género y un sistema de "Favoritos" que se guarde temporalmente.
7. **Sitio Web de un Evento / Concierto:** Información de la agenda, mapa interactivo (o simulación) y una sección interactiva para registrarse y "generar" un pase de entrada digital.
8. **Plataforma de Tareas / To-Do List Temática:** Un gestor de productividad enfocado en estudiantes (organizador de tareas de la universidad con prioridades).
9. **Mini-Trivia o Quiz Interactivo:** Un juego de preguntas y respuestas sobre cultura general o tecnología, con contador de puntos y pantalla de resultados al final.
10. **E-commerce de Productos Tecnológicos o Ropa (Simulado):** Vitrina de productos con filtros de precio, botón de "Añadir al carrito" y una pasarela de pago simulada que valide la tarjeta de crédito.

## Lista de Verificación (Checklist)

### 🏁 Al Inicio de Cada Sprint (Lunes - Revisión de Planificación)
*Revisión rápida para asegurar que los grupos no inicien la semana a la deriva.*

- [ ] **Sprint Activo:** ¿El equipo inició formalmente el Sprint en Jira (aparece el contador de tiempo)?
- [ ] **Backlog con Contenido:** ¿Hay tareas creadas para la semana o el tablero está vacío?
- [ ] **Vinculación Correcta:** ¿Todas las tareas de la semana están asignadas a la Épica correspondiente del Sprint actual?
- [ ] **Asignación de Responsables:** ¿Cada tarea en el tablero tiene la foto/nombre de un alumno o hay tareas "anónimas"?
- [ ] **Claridad:** ¿Las descripciones de las tareas contienen requisitos claros (Checklist/Criterios de aceptación) o solo títulos vagos?

---

### 🏃‍♂️ Fin del Sprint 1: Esqueleto Semántico (HTML)

- [ ] **Estructura en Git:** El repositorio de GitHub está creado y todos los integrantes del grupo tienen commits registrados.
- [ ] **Semántica HTML5:** El código utiliza etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) en lugar de abusar de `<div>` vacíos.
- [ ] **Navegación Interna:** Todos los enlaces del menú funcionan (al hacer clic llevan a las otras páginas del sitio, aunque estén en blanco).
- [ ] **Columna de Revisión:** Al menos 2 comentarios de un compañero que validó la maquetación.

---

### 🎨 Fin del Sprint 2: Diseño Visual (CSS)

- [ ] **Hoja de Estilos Limpia:** Existe un archivo `.css` externo bien enlazado. No hay estilos embebidos en el HTML (`style="..."`).
- [ ] **Layout Moderno:** El posicionamiento se resolvió usando Flexbox o CSS Grid (revisa que no usen `margin` con valores gigantescos o negativos para acomodar elementos).
- [ ] **Responsividad:** Al achicar el navegador o usar la herramienta de inspección en modo móvil, el contenido se adapta y el menú es accesible (no se genera barra de desplazamiento horizontal).
- [ ] **Validación Cruzada:** Las elementos visuales ya funcionan correctamente en el diseño.

---

### ⚡ Fin del Sprint 3: Interactividad (JavaScript)

- [ ] **Consola Limpia:** Al abrir el sitio web e interactuar con los botones o formularios, la consola de desarrollo (F12) no arroja errores en rojo (`Uncaught ReferenceError`, `TypeError`, etc.).
- [ ] **Manipulación del DOM:** Las interacciones modifican el HTML/CSS de forma dinámica (ej: agregar una clase para mostrar un modal, pintar texto de error en pantalla).
- [ ] **Validaciones Reales:** Los formularios bloquean el envío si los datos son incorrectos, mostrando alertas amigables al usuario.
- [ ] **Flujo de Código:** Contienen el enlace al Pull Request correspondiente de GitHub.

---

### 🌐 Fin del Sprint 4: Despliegue y Cierre Final

- [ ] **Sitio en Producción:** El enlace de GitHub Pages o Netlify es público, carga rápido y todas las imágenes y fuentes se visualizan correctamente (sin errores 404).
- [ ] **Repositorio Profesional:** El archivo `README.md` en GitHub detalla el nombre del proyecto, los integrantes, las tecnologías usadas y contiene el enlace al sitio en vivo.
- [ ] **Historial de Trabajo Equitativo:** Al revisar (sección de commits en GitHub), se evidencia que todos los estudiantes aportaron de forma similar al proyecto.
